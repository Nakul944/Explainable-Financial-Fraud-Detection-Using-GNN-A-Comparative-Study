# Experiment Results

This directory stores reproducible figures and metrics generated by the GCN, GraphSAGE, and GAT experiment notebooks.

- `GCN/`: baseline plots and metrics.
- `GraphSAGE/`: GraphSAGE plots and metrics.
- `GAT/`: reserved for the GAT experiment.
- `comparison/`: cross-model metrics and comparison figures, generated after all models are evaluated on the same test split.

PNG files are generated locally by running the corresponding notebook cells; they are not generated automatically by the GitHub commit.
